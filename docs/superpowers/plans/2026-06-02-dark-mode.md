# Dark Mode — Vista Pública H&H Residencial — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir toggle de modo claro/oscuro a la vista pública (home.jsx + HabitacionCard + FiltrosHabitaciones), persistido en localStorage, sin afectar el sistema interno.

**Architecture:** `darkMode: 'class'` en Tailwind; la clase `dark` se aplica al div raíz de `home.jsx` según el estado `isDark`. Los componentes hijos heredan el scope `dark:` automáticamente. El toggle vive en la navbar (desktop e icono en móvil). Persistencia en `localStorage` con clave `hh-theme`.

**Tech Stack:** React 18, Tailwind CSS v3, Vite, localStorage

---

## Referencia rápida de colores dark mode

| Elemento | Clase dark |
|---|---|
| Body wrapper | `dark:bg-gray-950` |
| Navbar / menú | `dark:bg-gray-900/95 dark:border-gray-700` |
| Cards y panels | `dark:bg-gray-900 dark:border-gray-700` |
| Texto principal | `dark:text-gray-100` |
| Texto secundario | `dark:text-gray-400` |
| Inputs / selects | `dark:bg-gray-800 dark:border-gray-600 dark:text-gray-100` |
| Badge disponibles | `dark:bg-green-900/20 dark:text-green-400 dark:border-green-900` |
| Emerald tag | `dark:border-emerald-800 dark:bg-emerald-900/20 dark:text-emerald-400` |
